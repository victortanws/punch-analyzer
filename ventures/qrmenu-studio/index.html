⬇️ Download your standalone menu

This generates one self-contained menu.html file — no server, no dependencies. Upload it to Netlify, GitHub Pages, or any static host, then use that URL in the QR & Print tab.

Your exported file bakes in the current restaurant name, theme, and menu items. Re-download any time you make changes.

Where to host it (free)

Pick whichever is easiest for your client:

  1. Netlify Drop — go to app.netlify.com/drop and drag in menu.html. You get a live URL in seconds.
  2. GitHub Pages — create a repo, upload the file as index.html, enable Pages in settings.
  3. Any cheap hosting / their existing website — upload via FTP as menu.html and link to it.

📱 Generate QR code

Paste the live URL of your hosted menu.html (from Netlify, GitHub Pages, etc.).

🖨️ Print table cards

Produces a printable sheet of table-tent cards with your QR code and restaurant name. Generate a QR code first.

Tip: print on cardstock, fold in half, tape at the seam — instant table tent.
