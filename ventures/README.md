# Venture Portfolio — 10 Sellable Micro-Apps

Ten zero-backend, single-file web apps, each built to be sold or monetized by a solo
entrepreneur. Every app ships as `index.html` (open it directly in a browser — no build,
no server, no API keys) plus a `README.md` with a concrete monetization playbook and a
`VALIDATION.md` written by an independent validator agent.

| App | Directory | Target buyer | Primary revenue model |
|---|---|---|---|
| InvoiceForge | `invoiceforge/` | Freelancers & micro-businesses | One-time purchase / white-label to bookkeepers |
| QR Menu Studio | `qrmenu-studio/` | Restaurants & cafés | $150–500 setup per venue + hosting retainer |
| BioLink Studio | `biolink-studio/` | Creators & local businesses | Paid page setups + theme packs |
| RoundTimer Pro | `roundtimer-pro/` | Boxers, gyms, HIIT athletes | Gym licensing / one-time unlock |
| ResumeAtlas | `resumeatlas/` | Job seekers, career coaches | Freemium template unlock / coach white-label |
| CertMaker | `certmaker/` | Trainers, course creators, schools | One-time purchase + bulk-generation gigs |
| QuoteCalc Builder | `quotecalc-builder/` | Service businesses (cleaners, contractors) | $100–300 per custom calculator sold |
| PunchCard Loyalty | `punchcard-loyalty/` | Cafés, salons, barbershops | $99 setup + monthly per shop |
| LaunchPage Studio | `launchpage-studio/` | Indie founders, local businesses | $50–200 per landing page freelancing |
| MacroCoach | `macrocoach/` | Fitness & boxing coaches | $49 white-label license / lead-magnet funnel |

Why these ten: local-business service plays (QR menus, loyalty cards, quote calculators)
monetize through direct sales with no marketing budget; freelancer/creator tools
(invoices, resumes, bio links, landing pages, certificates) monetize through marketplaces
and freemium unlocks; and the two fitness tools (round timer, macro calculator) plug
directly into an existing combat-sports audience.

Status: building — this table and per-app validation reports are finalized after the
validator agents run.
