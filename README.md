# 🥊 Punch Power Analyzer

An AI-powered web app that analyzes and scores your punching technique in real-time!

## Features
- Real-time pose tracking using MediaPipe
- Scores based on:
  - **Speed** - How fast your punch is
  - **Power** - How close your fist gets to the camera
  - **Extension** - Arm straightness
  - **Hip Rotation** - Proper body mechanics
  - **Form** - Overall technique
  - **Battle Cry** - Did you shout? 💪

## Try It Live
[Click here to try it!](https://victortanws.github.io/punch-analyzer/)

## How to Use
1. Open the web app in your browser (Chrome or Edge recommended)
2. Click "Start Camera" and allow camera/microphone access
3. Position yourself so your full body is visible
4. Click "Ready to Punch" when positioned
5. Throw your best punch after the countdown!

## Technologies Used
- MediaPipe Pose Detection
- HTML5 Canvas
- Web Audio API
- Vanilla JavaScript

## Local Development
Simply open `index.html` in your browser - no build process needed!
